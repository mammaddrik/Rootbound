## About

This section documents my 15-day learning journey through Linux, covering its fundamental concepts, command-line operations, system management, and practical applications.

The learning materials are organized into separate directories, with each directory representing one day of study. Each day contains notes, explanations, commands, and practical exercises related to the topics covered.

The goal is to develop a solid understanding of Linux through structured study and hands-on practice while maintaining a detailed record of the learning process.
